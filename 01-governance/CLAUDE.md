# CLAUDE.md

Guidance for AI coding assistants working in this repository has moved to the repo root:
**[`/CLAUDE.md`](../CLAUDE.md)**.

Claude Code auto-loads project instructions from a repository's root `CLAUDE.md`, not from a
nested one, so keeping the real guidance here would mean it's silently ignored. This file
previously held a stale, mis-copied vendored guide for a *different* repository (the product
monorepo's build/routing/backend guidance, which doesn't apply here); it has been replaced with
this pointer to avoid misleading future edits. Update `/CLAUDE.md`, not this file.
