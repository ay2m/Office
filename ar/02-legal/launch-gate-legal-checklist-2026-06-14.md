# فلاي قاكا (Fly GACA) — قائمة التحقق القانونية لبوابة الإطلاق
**الوثيقة:** launch-gate-legal-checklist-2026-06-14.md
**الإصدار:** 1.0 — 2026-06-14
**أعدّها:** مساعد ذكاء اصطناعي (Claude) — لمراجعة المؤسس
**الحالة:** وثيقة حيّة — تُحدَّث مع اكتمال البنود. ومرجوعة إلى: legal-gap-audit-2026-06-14.md، وfly-gaca-review-action-plan.md §6–7، وبوابة الإطلاق في ROADMAP.

> **ليست استشارة قانونية.** قائمة التحقق هذه وثيقة تتبّع لعمليات الأعمال فحسب. وهي لا تحلّ محل المشورة من محامٍ سعودي مرخّص مؤهل. ويجب أن تتلقّى جميع البنود الموسومة بـ "تحتاج محامياً" مراجعة قانونية مهنية قبل اعتبارها مكتملة.

## نظرة عامة — ملخص بوابة الإطلاق

ثلاثة أحداث إطلاق متمايزة لها متطلبات قانونية مختلفة:

| حدث الإطلاق | الوصف | البوابة القانونية |
|-------------|-------------|-----------|
| **L0 — افتتاح خفيف (المكتبة، دون حسابات)** | وصول عام للمكتبة المجانية؛ دون حسابات؛ دون مدفوعات | الحد الأدنى — الشروط + إخلاء المسؤولية + الرأي القائم بشأن الاسم |
| **L1 — إطلاق الحسابات** | تسجيل المستخدمين، والفئة المجانية، وتحويل قائمة الانتظار | اكتمال قائمة P0 الكاملة؛ وتحديث إشعار الخصوصية؛ وإشعار ملفات الارتباط مفعّل |
| **L2 — إطلاق المدفوعات (Pro / Exam Pass)** | اشتراكات مدفوعة عبر مُيسِّر (Moyasar)؛ وضريبة القيمة المضافة لدى هيئة الزكاة والضريبة والجمارك (ZATCA) | اكتمال L1 + الكيان + هيئة الزكاة والضريبة والجمارك + سياسة الاسترداد + اتفاقية معالجة البيانات للأعمال (B2B DPA) |
| **L3 — إطلاق الأعمال مع الأكاديميات (B2B)** | اتفاقيات أكاديميات موقّعة؛ ومعالجة بيانات الطلاب المتدربين | اكتمال L2 + توقيع اتفاقية معالجة البيانات للأعمال مع كل عميل |

## مرجع سريع: ما الذي يرفع الحجب عن الإطلاق الخفيف (L0)؟

1. [ ] P0-1 الرأي بشأن حقوق المتن — أو تبنّي نموذج احترازي بالربط فقط ريثما يصدر الرأي
2. [ ] P0-2 الرأي بشأن الاسم — أو الإطلاق تحت "Fly GACA" بمخاطرة مقبولة (قرار المؤسس بعد قراءة قائمة التحقق هذه)
3. [x] P0-3 شروط الاستخدام — مُصاغة (تحتاج مراجعة المحامي + إصلاح البريد الإلكتروني قبل النشر)
4. [x] P0-4 إخلاء المسؤولية — مُصاغ (يحتاج مراجعة المحامي + إصلاح البريد الإلكتروني قبل النشر)

6. [ ] التعاقد مع محامٍ — التواصل مع المحامين في القائمة المختصرة (lawyer-shortlist.md)؛ وإرسال الموجزات (Lawyer-Brief-Corpus-Rights + Lawyer-Brief-Name-Opinion + lawyer-brief.md القائم)
