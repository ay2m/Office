> [!IMPORTANT]
> **وثائق تشغيلية داخلية.** مستودع `iflygaca/Office` («المكتب») هو المستودع المركزي لوثائق الحوكمة والاستراتيجية والعقود القانونية وأطر الامتثال للأنظمة واللوائح السعودية الخاصة بمنظومة فلاي قاكا. وهو لا يحتوي على أي شيفرة مصدرية للتطبيقات البرمجية.
>
> **فلاي قاكا منصة تعليمية وتدريبية مستقلة** غير تابعة للهيئة العامة للطيران المدني (GACA). المصدر الرسمي والمعتمد لجميع اللوائح والأنظمة هو موقع الهيئة دائمًا [gaca.gov.sa](https://gaca.gov.sa).

## 🇸🇦 منظومة الامتثال للأنظمة واللوائح السعودية

1. **الفوترة الإلكترونية (زاتكا ZATCA المرحلة الثانية):** توليد ملفات الفواتير الضريبية بصيغة UBL 2.1 XML المتوافقة مع متطلبات هيئة الزكاة والضريبة والجمارك، مع التشفير بخوارزمية SHA-256 ورمز الاستجابة السريع TLV.
2. **نظام حماية البيانات الشخصية (PDPL):** تقييم أثر حماية البيانات (DPIA)، وإشعارات الخصوصية المعتمدة وفق لوائح الهيئة السعودية للبيانات والذكاء الاصطناعي (سدايا SDAIA).
3. **وزارة الاستثمار (MISA) والسجل التجاري:** هياكل تأسيس الشركات، واللوائح الداخلية المعتمدة من وزارة التجارة.
4. **نظام العمل ونطاقات:** عقود عمل ثنائية اللغة متوافقة مع منصة «قوى» وتصنيفات التوطين السعودية.

## 🖨 خط إنتاج المطبوعات الآلي (A4 PDF Pipeline)

يتضمن المستودع خط إنتاج آلي يعتمد على **Node.js 20+** ومتصفح **Chromium** لتوليد ملفات PDF عالية الدقة بمقاس A4 لجميع الوثائق:

```bash
cd tools/print
npm ci                  # تثبيت الحزم المساندة
npm run build           # بناء تزايدي للوثائق المعدلة فقط
npm run check           # التحقق من سلامة البيانات الوصفية وحداثة الملفات
npm run check:facts     # التحقق من مطابقة حقائق الكيان عبر المستودعات
```
