# النسخة العربية (`ar/`) — توثيق مكتب فلاي جاكا

هذا المجلد نسخة عربية موطّنة من توثيق المستودع، بصياغة **العربية الفصحى الحديثة بالاصطلاح السعودي الرسمي**.

## كيف يعمل هذا المجلد

- يطابق هذا المجلد بنية المستودع الإنجليزي **مطابقةً تامة**: لكل ملف `‎.md` في الجذر نظير بالمسار نفسه تحت `ar/`.
  مثال: `02-legal/terms-of-use-draft-2026-06-14.md` ← `ar/02-legal/terms-of-use-draft-2026-06-14.md`.
- تُبقى **أسماء الملفات والمجلدات بالإنجليزية** (kebab-case) كما هي؛ المُترجَم هو **المحتوى** فقط — وذلك لإبقاء
  الشجرتين قابلتين للمقارنة والمزامنة بسهولة.
- **النسخة الإنجليزية هي المصدر المرجعي الأساسي.** عند أي تعارض، تُعتمد الإنجليزية.

## ما الذي يشمله / لا يشمله

- **يشمل:** جميع ملفات `‎.md` (99 ملفًا).
- **لا يشمل:** الملفات الثنائية التي لا يمكن ترجمتها بتحرير النص — `‎.docx` (92)، `‎.xlsx` (8)، `‎.pdf` (4)،
  `‎.pptx`، الصور (`‎.png`/`‎.jpg`/`‎.svg`/`‎.psd`)، و`‎.gsheet`. كما لا يشمل ملفات `‎.html` و`‎.csv`.
  الروابط المؤدية إلى هذه الملفات تشير إلى النسخة الإنجليزية الأصلية.
