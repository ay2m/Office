## 1. سياق المشروع

فلاي قاكا **منصّة طيران رقمية تعليمية ومكتبة تنظيمية مفتوحة** لقطاع الطيران المدني
السعودي. الشعار: *"كل الطيران السعودي، في قمرة واحدة."*
تخدم الطيّارين والمشغّلين والمدرّبين وطلاب الطيران في المملكة العربية السعودية.

| | |
|---|---|
| النطاق الرئيسي | flygaca.com (أصل واجهة API: api.flygaca.com) |
| مستودع المنتج | github.com/ay2m/FlyGACA — تطبيق الويب + خلفية Express + المتن التنظيمي |
| مستودعات أخرى | ay2m/Captain-Adel (خدمة captadel.com) · ay2m/FlyGACA-ios (عائلة SwiftUI الأصلية) · ay2m/Office (شجرة الوثائق هذه) · ay2m/FlyGACA-app (السلف **المؤرشف** — لا يُستشهد به بوصفه قائمًا أبدًا) |
| المالك | الكابتن عادل السبيعي — كبير المدرّبين، ATPL، CFII |
| نمط البناء | مؤسّس منفرد · بلا موعد نهائي ثابت · تسليم مرحلي |

**المشكلة التي يحلّها.** يتدبّر الطيّارون السعوديون ملفات PDF متناثرة، وسجلّات طيران ورقية، وحاسبات،
ومواقع مرجعية كثيرة كي يدرسوا ويبقوا على اطلاع. ولوائح الطيران المدني السعودي (GACAR)
غنيّة، ومتطوّرة، وموزَّعة عبر عشرات الأجزاء. ويعالج فلاي قاكا
الوصول المُشظّى، وبطء البحث، وغياب أدوات الطيّار المدركة لـ GACAR.

## 2. الحالة الراهنة — مبنيّ، لا من الصفر

**لا تبنِ من الصفر.** فالمنتج قابل للحياة: المكتبة التنظيمية (الوثائق، والمخططات، وخريطة المطارات،
وتغذية تغييرات المتن)، ومحادثة الكابتن عادل، و55 أداة طيران، وشاشة المجال الجوي (HUD)،
ومركز التعلّم/الأدلة، وحزمة الدراسة (الاختبار القصير، والبطاقات التعليمية، والمدرسة الأرضية،
والاختبار التجريبي، والمسارات، وحزم التحضير للاختبارات)، وأسطح الحساب المصادَق عليها (لوحة
المعلومات، وسجل الطيران، والحداثة، والسجلات، والإعدادات)، والأسعار/المدارس/سلّة الدفع، وصفحة
واجهة API المرخّصة، ولوحة مسؤول المؤسسة (B2B) — كلها قائمة. وتشحن عائلة SwiftUI أصلية منفصلة
تطبيقين على App Store (ELPT وAIP).

وحين لا تعرف أهو مبنيّ أم لا، **فاسأل** — ولا تفترض في أي من الاتجاهين.

## 3. الاستراتيجية

قمع واحد: **مكتبة GACAR المجانية** هي الإسفين (الأقل خطرًا، الأعلى ثقةً،
ونافعة وحدها) ← **الكابتن عادل**، مساعد الذكاء الاصطناعي ذو المصدر المُقتبَس، هو **الطبقة المميَّزة
المدفوعة** ← **مدارس الطيران والمشغّلون** الذين يشترون مقاعد لطلاب الطيران هم محرّك الإيرادات، مع
**واجهة API المرخّصة** بالعدّاد خطًّا ثالثًا.

الكابتن عادل دماغ واحد ببابين أماميين — داخل flygaca.com، وعبر captadel.com.
**لا قاعدتا شيفرة أبدًا.**

## 4. القيود القانونية والامتثالية — غير قابلة للتفاوض

تَعلو هذه على كل الاعتبارات الأخرى.

- فلاي قاكا أداة **تعليمية** و**غير مرتبطة** بالهيئة العامة للطيران
  المدني. والمصدر الرسمي المرجعي لأي لائحة هو دائمًا الهيئة العامة للطيران المدني
  (gaca.gov.sa).
- لا يجوز لأي إجابة أو ميزة أو نسخة أن توحي بصفة رسمية. وإخلاء المسؤولية مكوّن مشترك — لا
  تضمّنه سطريًّا أبدًا، ولا تُعِد صوغه أبدًا.
- يعالج المشروع بيانات شخصية ويجب أن يمتثل لـ **نظام حماية البيانات الشخصية السعودي (PDPL)**. وتبقى
  البيانات الشخصية والحوسبة التي تلامسها داخل المملكة.
- **ثنائية اللغة إنجليزي/عربي مع RTL من الدرجة الأولى.** وكل نص جديد يحتاج إلى مفتاح في *كلتا*
  حزمتي اللغة؛ وتفشل مجموعة الاختبارات عند أي مفتاح موجود في إحداهما وغائب عن الأخرى.
- يجب احترام المخاطر المفتوحة في القسم 6 — لا تبنِ كأنها محسومة.

## 5. سياسة متن قاعدة المعرفة

ما يجوز للكابتن عادل أن يتعلّم منه قرار قانوني **و** سلامة. ثلاث مراتب، ثابتة:

- **استضِف — النواة الآمنة:** أجزاء GACAR، ومخطّطات المعلومات الجوية السعودية (AIPs)، والتعميمات/الإرشادات الاستشارية للهيئة العامة للطيران المدني. كلها
  منشورة من الهيئة.
- **استضِف — أصلي:** مادة التدريب والامتحان الخاصة بفلاي قاكا. أما بنوك الأسئلة المكشوطة من طرف
  ثالث فـ**غير** مسموح بها.
- **لا تستضِف — اقتبس وأحِل فقط:** ملاحق ICAO / SARPs (حقوق ICAO؛ المضمون
  منعكس أصلًا في GACAR) وأدلة الطائرات / POH / AFM (حقوق الصانع؛
  والبيانات الخاصة بطائرة معيّنة خطر سلامة إن اقتُبست بإطلاق). يقتبس الكابتن عادل
  هذه ويربط إلى المصدر الرسمي؛ ولا يعيد إنتاجها أبدًا ولا يحلّ محلّ
  POH/AFM.
- **حداثة AIP:** تتغيّر مخطّطات المعلومات الجوية كل دورة AIRAC مدّتها 28 يومًا. ويجب أن تحمل كل إجابة مصدرها AIP
  تاريخ سريان وسطر *"ليس للاستخدام التشغيلي — تحقّق من AIP الحالي
  وإشعارات الطيّارين NOTAMs."*

## 6. مخاطر مفتوحة

1. **حقوق إعادة التوزيع** لـ GACAR وAIPs والتعميمات الاستشارية. أكِّد الموقف السعودي أو احصل على
   إذن الهيئة العامة للطيران المدني. مؤقتًا: اذكر المصدر والإصدار واربط إلى نسخة الهيئة.
2. **اسم "GACA"** يستند إلى هوية السلطة الحكومية — تعرّض للعلامة التجارية و
   انتحالها. يحتاج فحص علامة تجارية وإخلاء مسؤولية لا يُفوَّت في كل مكان.
3. **flygaca.sa** غير معطّل لكنه غير مسجَّل؛ وقد يثير مقطع "gaca" مراجعة اسم لدى SaudiNIC.
   ويبقى flygaca.com هو المعتمد في الحالين.

ليست استشارة قانونية — ينبغي لمحامي ملكية فكرية سعودي تأكيد البندين 1 و2.

## 7. الاستضافة والبنية التحتية

**Google Cloud هو الأصل المعتمد. ولا وجود لـ Firebase في هذا المنتج إطلاقًا** — لا Hosting، ولا
Auth، ولا Functions، ولا Firestore، ولا App Check، ولا خطة Blaze/Spark. والمدفوعات عبر
**Moyasar**، لا Stripe أبدًا.

| الشأن | ما الذي يشغّله |
|---|---|
| تطبيق الصفحة الواحدة (`dist/`) | دلو Cloud Storage خلف موازن تحميل HTTPS |
| واجهة API ‏(`server/`) | خدمة Express 5 واحدة على **Cloud Run**، في الإقليم **`me-central2`** (الدمام) |
| مخزن البيانات | **Cloud SQL for PostgreSQL**، في الإقليم نفسه، عبر مقبس unix خاص بـ Cloud SQL |
| الأسرار | **Google Secret Manager**، تُركَّب في إصدار Cloud Run |
| التجديدات | **Cloud Scheduler** ← `POST /api/billing/renew` مع سرّ cron مشترك |
| المرايا | عامل Cloudflare Worker + Netlify / Vercel، كلٌّ منها يوكّل `/api/*` عائدةً إلى أصل Cloud Run نفسه |
| الخادم الافتراضي الخاص في الاتحاد الأوروبي (باريس) | استيعاب المتن / بناء مقاطع RAG / التقييمات / البيئة التجريبية — **بيانات عامة فقط**، ولا يكون الباب الأمامي أبدًا |

**حدّ PDPL:** تبقى الحسابات والملفات الشخصية وسجل الطيران واستعلامات المستخدمين الحقيقية في
`me-central2` (الدمام). و**`me-central1` هي الدوحة، قطر** — ليست داخل المملكة، وليست آمنة وفق
PDPL أبدًا. وأبقِ كل سطح API جديد تحت `/api/*` كي يستمرّ عمل وكيل المرايا من الأصل نفسه وسياسة
أمن المحتوى الصارمة.

## 8. المكدّس التقني

| الطبقة | الخيار |
|---|---|
| الواجهة الأمامية | **React 19 + TypeScript (صارم) + Vite**؛ وحدات CSS مع رموز التصميم والخصائص المنطقية؛ i18next للإنجليزية/العربية؛ تطبيق ويب تقدّمي عبر vite-plugin-pwa |
| الواجهة الخلفية | **Express 5** ‏(TypeScript) على Cloud Run — وحدات سياسة `*-core` صافية، وأغلفة مسارات رفيعة، وكل SQL في وحدة مخزن واحدة |
| قاعدة البيانات | **PostgreSQL** ‏(Cloud SQL)؛ ترحيلات SQL أحادية الاتجاه |
| المصادقة | بريد + كلمة مرور (scrypt) وGoogle عبر OAuth من جهة الخادم؛ رمز JWT بخوارزمية HS256 داخل ملف تعريف ارتباط HttpOnly |
| الاستحقاقات | **مملوكة للخادم.** لا يوجد مسار يتيح للعميل كتابة خطته أو أرصدته أو ملكيته لحزمة |
| المدفوعات | **Moyasar** — أداة مستضافة + تأكيد من خادم إلى خادم، والويبهوك دفاعًا عميقًا؛ والفوترة الإلكترونية لدى ZATCA |
| مساعد الذكاء الاصطناعي | الكابتن عادل — **Gemini عبر Genkit**، وRAG على متن GACAR، والتأصيل يُحسب من جهة الخادم |
| الحاسبات | وحدات صافية خالية من DOM، مُختبَرة بالوحدات، خارج طبقة الواجهة |
| التطبيقات الأصلية | غلاف Capacitor لتطبيق الويب؛ وعائلة SwiftUI أصلية منفصلة في `ay2m/FlyGACA-ios` |
| الاختبار | **Vitest** (سقّاطة تغطية) + **Playwright** من طرف إلى طرف وإمكانية الوصول |

لا تُدخل Firebase ولا Stripe ولا تبديل إطار عمل. والاعتماديات الجديدة تحتاج إلى سبب — تفقّد ما
لدى المستودع أصلًا.

## 9. العمل الجاري

المراحل الأصلية 0–6 (الأسس ← المكتبة ← الكابتن عادل ← الحسابات ← العربية/دون اتصال ← المال ←
الوصول) **منجَزة أو متجاوَزة**. والعمل الحالي تدريجي ويُتتبَّع في ملف `ROADMAP.md` في مستودع
المنتج، وهو المرجع. اسأل عن البند قيد التنفيذ بدل استنتاج مرحلة.

## 10. بنية المستودع (`ay2m/FlyGACA`)

```
src/                React app
  pages/            one folder per page
  router.tsx        the single route table
  calc/             pure, DOM-free logic (unit-tested)
  lib/              typed frontend services
  i18n/             en.json + ar.json — always edited together
  components/  hooks/  styles/   (tokens.css is the design-token source of truth)
server/             the Express service — its own npm package with its own CI gate
server/migrations/  the SQL schema
public/data/        the regulatory JSON corpus + indexes — fetched at runtime, never bundled
content/            authored markdown (guides, regulations)
scripts/            Node ESM content and build pipelines
docs/               engineering docs (RUNBOOK-deploy, BILLING, LICENSED-API, …)
e2e/                Playwright specs
```

## 11. مسار الأعمال والشركة

- الكيان مسجَّل؛ والتسجيل في ضريبة القيمة المضافة لدى **ZATCA** والفوترة الإلكترونية «فاتورة» على
  المسار المالي.
- برنامج الامتثال لـ **PDPL** وتقييم أثر حماية البيانات (DPIA) يغطّيان البيانات الشخصية التي
  تحملها أسطح الحساب.
- **التسعير (بالريال السعودي، شامل ضريبة القيمة المضافة):** Pro **79/شهر · 649/سنة**؛ وتصريح موسم
  الاختبارات **299** لمدة 90 يومًا؛ وحزم التحضير للاختبارات بشرائح **249 / 399 / 499**؛ وحزمة
  الوصول الشامل **1,499**؛ وأرصدة المحادثة **39**؛ وباقة الدفعة B2B **12,000/سنة**، والأكاديمية
  **39,000**، والمؤسسة **من 72,000**؛ وواجهة API المرخّصة **499 / 1,999 / 6,999** شهريًّا.
  **لا توجد طبقة طلاب (Student).** الطبقة المجانية: المكتبة كاملة، وكل أدوات الطيران الـ**55**،
  و**5 أسئلة للكابتن عادل في اليوم**.
- **النفاذ إلى السوق:** شروحات تنظيمية من LinkedIn المؤسِّس؛ والبذر مع مدارس الطيران ومجتمعات
  الطيّارين؛ مكتبة مجانية ← مساعد وأدوات مدفوعة ← مقاعد B2B لمدارس الطيران.

## 13. قواعد تشغيل الوكيل

- **اقرأ ملف `CLAUDE.md` الخاص بالمستودع أولًا.** فهو الحاكم.
- عندما يكون الطلب غامضًا، **اسأل قبل الافتراض** — خصوصًا في أي شيء يمسّ
  اللوائح، أو القيود القانونية، أو سياسة المتن.
- أبقِ كل محتوى الطيران والتنظيم **دقيقًا ومحافظًا**. الهيئة العامة للطيران المدني هي السلطة
  الوحيدة؛ ويذكّر كل سطح تنظيمي المستخدمين بالتحقّق من المصادر الرسمية.
- التزِم بالأقسام 4 و5 و6 في كل تغيير. ليست اختيارية.
- وائِم اصطلاحات المستودع القائمة. TypeScript صارم — لا `any`، ولا `@ts-ignore`، ولا `!` لإسكات
  المصرّف.
- اكتب الاختبارات مع الشيفرة و**شغِّلها**. وشغّل بوّابة التحقّق الكاملة للمستودع قبل الإبلاغ بإنجاز
  مهمّة؛ ولحزمة الخادم بوّابتها المنفصلة.
- اصنع التزامات صغيرة قابلة للمراجعة. وأشِر صراحةً إلى أي تبعة أمنية أو متعلّقة بسيادة البيانات.
- ابنِ للإنجليزية والعربية (RTL) من البداية في أي سطح موجّه للمستخدم.

## 14. تعريف الإنجاز

لا تُنجَز المهمّة إلا عندما: تُبنى الشيفرة وتعمل؛ وتجتاز اختبارات التغيير؛ وتكون بوّابة التحقّق
خضراء؛ وتتحرّك حزمتا اللغة معًا؛ وتُصان القيود القانونية/المتن؛ ويُشار إلى أي تبعة أمنية أو
متعلّقة بإقامة البيانات. أما العمل الجزئي، أو الاختبارات الفاشلة، أو المُخرَج غير المتحقَّق منه فـ**ليس**
إنجازًا.
