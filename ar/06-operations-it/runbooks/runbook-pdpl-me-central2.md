# دليل تشغيل — إقامة بيانات نظام حماية البيانات الشخصية (PDPL): الانتقال إلى me-central2 (الدمام) — مكتمل

> [!WARNING]
> **أُحيل هذا الدليل إلى التقاعد في 2026-08-19 —** الترحيل الذي خطّط له **قد أُنجز**، ثم تجاوزه
> تغيير أكبر: فقد نُقل المنتج عن Firebase بالكامل. وكل خطوة تحوّل واردة أدناه (استعادة Firestore،
> و`firebase auth:import`، وأسرار Cloud Functions، ومشروع `flygaca-app`، وويبهوكات
> Stripe/RevenueCat، والحوسبة المؤقتة في `me-central1`) تشير إلى بنية تحتية لم تعد موجودة. لا شيء
> هنا قابل للتنفيذ، وقائمة «ما يزال معطَّلًا / يحتاج إليك» ليست قائمة مهام حيّة.
>
> **أما النتيجة، وهي المهم:** البيانات الشخصية والحوسبة التي تلامسها في **`me-central2` (الدمام)** —
> Cloud SQL for PostgreSQL وواجهة Cloud Run البرمجية، في الإقليم نفسه، متصلتان عبر مقبس unix خاص
> بـ Cloud SQL. وقد أُغلقت الفجوة المؤقتة في `me-central1` (الدوحة).
>
> **اذهب بدلًا منه إلى:** [`../hosting-facts.md`](../hosting-facts.md) — فقسم حدود PDPL فيه هو
> البيان الحالي لما يقيم أين ولماذا — وإلى `docs/RUNBOOK-deploy.md` في
> [`ay2m/FlyGACA`](https://github.com/ay2m/FlyGACA).

## التاريخ، في أربعة أسطر

يستحقّ الحفظ، لأنه سبب ذكر هذه الحدود بهذه الصراحة في كل موضع آخر:

1. وضع المشروع الأصلي قاعدة Cloud Firestore في **`nam5` (المنطقة الأمريكية متعدّدة الأقاليم)** بينما
   كان إشعار الخصوصية العلني يزعم أنها في الدمام. وموقع Firestore دائم، فلم يكن بالإمكان نقل قاعدة
   البيانات.
2. أُنشئ مشروع جديد وقاعدة بياناته في **`me-central2`**، ورُحِّلت سجلات البيانات الشخصية الثمانية.
   وعملت الحوسبة **مؤقتًا في `me-central1` (الدوحة)** لأن Cloud Run في الدمام لم يكن متاحًا بعد على
   الحساب.
3. مُنح لاحقًا الوصول إلى Cloud Run في `me-central2`، فأُغلقت فجوة المعالجة.
4. ثم حلّ Cloud Run + Cloud SQL محلّ منظومة Firebase بأكملها، وحُذفت تلك المشاريع.

## القاعدة التي نجت من ذلك كلّه

> تبقى كل البيانات الشخصية — الحسابات، والملفات الشخصية، وسجل الطيران، واستعلامات المستخدمين
> الحقيقية — داخل المملكة. أما العمل على المتن العام فيمكن أن يجري على VPS الأوروبي.

والتصحيح الذي يجب ألّا يضيع أبدًا: **`me-central1` هي الدوحة، قطر.** ليست الرياض، ولا «الصندوق
داخل المملكة»، وليست آمنة وفق PDPL. و`me-central2` (الدمام) هي الإجابة الوحيدة داخل المملكة.
