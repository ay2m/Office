# دليل تشغيل — إطلاق Fly GACA

أخذ المنتج إلى البيئة الحيّة. تسلسل النشر الآلي **غير** مكرَّر هنا — فهو يقيم مع الشيفرة، في
`docs/RUNBOOK-deploy.md` داخل [`iflygaca/FlyGACA`](https://github.com/iflygaca/FlyGACA). وهذه الصفحة هي
غلاف الإطلاق المحيط به: ما الذي يُطرَح، والبوّابات التي يجب أن تكون خضراء أولًا، واختبار التدخين،
والمفاتيح التجارية/القانونية التي هي من شأننا لا من شأن أداة النشر.

كل ما يلي يحتاج إلى عمليات تسجيل دخولك أنت إلى Google Cloud وGitHub وMoyasar، ولذلك يُنفَّذ على
جهازك، لا من جلسة مساعد.

---

## ما الذي يُطرَح

بناء Vite واحد (`dist/`) وخدمة Express واحدة:

- **المكتبة التنظيمية** — أجزاء GACAR، والأدلة (handbooks)، والمطارات، والمخططات، وخريطة المطارات،
  وتغذية تغييرات المتن.
- **الكابتن عادل** — محادثة RAG، موثَّقة بالإحالة إلى الجزء/القسم بالضبط. راجع
  [`runbook-captain-adel.md`](runbook-captain-adel.md).
- **55 أداة طيران**، وشاشة المجال الجوي للمملكة (HUD)، ومركز التعلّم/الأدلة، وأسطح الدراسة (الاختبار
  القصير، والبطاقات التعليمية، والمدرسة الأرضية، والاختبار التجريبي، والمسارات، وحزم التحضير
  للاختبارات، وأوراق الدراسة).
- **الحسابات** — لوحة المعلومات، وسجل الطيران، والحداثة (currency)، والسجلات، والإعدادات — مع تسجيل
  الدخول بالبريد/كلمة المرور أو عبر Google.
- **الأسطح التجارية** — الأسعار، والمدارس، وسلّة الدفع، ولوحة الدفعات لمسؤول المؤسسة (B2B)، وصفحة
  واجهة الكابتن عادل البرمجية المرخّصة.

يُقدَّم تطبيق الصفحة الواحدة (SPA) من دلو Cloud Storage خلف موازن تحميل HTTPS؛ ويذهب `/api/*` إلى
خدمة Cloud Run، المسنودة بـ Cloud SQL. وكل ذلك في `me-central2` (الدمام). راجع
[`../hosting-facts.md`](../hosting-facts.md).

## 1 — البوّابات التي يجب أن تكون خضراء قبل النشر

شغّلها من نسخة نظيفة من `iflygaca/FlyGACA`:

```sh
npm run verify        # typecheck → lint → format:check → test → build → check:bundle → check:perf
npm run test:e2e      # Playwright, incl. accessibility
```

والخادم حزمة npm مستقلة ببوّابتها الخاصة — و`verify` في الجذر **لا** يغطّيها:

```sh
cd server && npm run lint && npm test && npm run build
```

اثنتان من تلك البوّابات ذات صلة مباشرة بالإطلاق بحدّ ذاتهما: يفشل `check:bundle` إذا تجاوزت شيفرة
JavaScript الابتدائية المضغوطة ميزانيتها، ويفشل اختبار تكافؤ التوطين (i18n) عند أي سلسلة موجودة في
لغة دون الأخرى — فلا يمكن أن يُطرَح إطلاق نصف مترجَم بالخطأ.

## 2 — النشر

اتّبع `docs/RUNBOOK-deploy.md` في مستودع المنتج، بترتيبه. وإجمالًا:

1. زوِّد (أو أكِّد) مشروع Google Cloud، ونسخة Cloud SQL، وعميل OAuth، ومدخلات Secret Manager، ومهمّة
   التجديد في Cloud Scheduler.
2. طبِّق ترحيلات المخطط المعلّقة قبل أن يخدم الإصدار الجديد أي حركة.
3. انشر واجهة API إلى Cloud Run — **واضبط كل سعر تنوي البيع به**؛ فالسعر غير المضبوط يجعل صيغة الدفع
   تلك تفشل بصوت عالٍ بدل أن تحصّل 0 ريال.
4. ابنِ تطبيق الصفحة الواحدة مقابل أصل واجهة API، وزامِن `dist/` إلى الدلو.
5. تأكّد من أن موازن التحميل يوجّه `/*` إلى الدلو و`/api/*` إلى خدمة Cloud Run.

> [!IMPORTANT]
> أبقِ كل سطح API جديد تحت `/api/*`. فعامل Cloudflare Worker ومرايا Netlify / Vercel جميعها توكّل
> `/api/*` عائدةً إلى أصل Cloud Run نفسه بوصفه إعادة كتابة من الأصل ذاته — وهذا ما يُبقي ملف تعريف
> ارتباط الجلسة على الموقع نفسه (same-site) ويُبقي سياسة أمن المحتوى عند `connect-src 'self'`.

### النطاقات

`flygaca.com` هو النطاق المعتمد، و`api.flygaca.com` هو أصل واجهة API. وترسل المرايا
`X-Robots-Tag: noindex` لأي مضيف ليس `flygaca.com`، فلا يمكن أن يُفهرَس مضيف معاينة بالخطأ. وتبقى
`flygaca.sa` للتحويل فقط بانتظار الرأي في الاسم — راجع
[`../hosting-facts.md`](../hosting-facts.md).

## 3 — اختبار تدخين بعد النشر

على الأصل الحيّ:

- تُعرَض الصفحة الرئيسية (لوحة البِنتو)، وتفتح لوحة الأوامر وتتنقّل.
- يُحمَّل `/library`؛ افتح جزءًا من GACAR ومخططًا؛ ويرسم `/library/map` المطارات؛ ويسرد `/updates`
  تغييرات المتن.
- يجيب `/chat` عن سؤال في GACAR **باستشهادات ترتبط ارتباطًا عميقًا داخل المكتبة**، ويتصرّف عدّاد
  الطبقة المجانية كما ينبغي (5 أسئلة في اليوم).
- تحسب بضع أدوات، وتُنتج أزرار **نسخ الرابط** فيها عنوانًا يستعيد المدخلات — وهذا هو الفحص الذي
  يثبت أن الصفحة تعتمد خطّاف حالة الرابط لا الحالة المحلية.
- يعمل اختبار دراسة قصير؛ ويُوقِّت الاختبار التجريبي ويُصحِّح؛ ويستمر التقدّم عبر إعادة التحميل.
- التسجيل ← التحقق بالبريد ← تسجيل الدخول عبر Google ← كتابة قيد في سجل الطيران ← رؤية الحداثة
  تتحدّث.
- `/pricing` ← `/checkout` بمفتاح Moyasar حيّ: أتمِم عملية شراء حقيقية واحدة منخفضة القيمة، وتأكّد
  من أن مرحلة العودة تمنح الاستحقاق، ثم تأكّد من أن الويبهوك **لا** يمنحه مرّتين.
- بدّل إلى العربية: تنقلب الوثيقة إلى الاتجاه من اليمين إلى اليسار، ولا يُعرَض أي مفتاح كنصّ حرفي.
- يُظهر عنوان URL مختلَق صفحة 404 ذات الهوية، ويظلّ التطبيق يعمل دون اتصال بالنسبة إلى المكتبة بعد
  أول زيارة.

راقِب سجلات Cloud Run طوال الساعة الأولى: يُعيد `GET /healthz` الرمز 503 حتى تستجيب قاعدة البيانات،
فالرمز 503 المبكر يعني قاعدة البيانات لا التطبيق.

## 4 — المفاتيح التجارية

هذه قرارات لا خطوات نشر، وهي التي تجعل الإطلاق *إطلاقًا* فعلًا:

- **التسعير حيّ على الخادم.** تُضبط الأسعار على إصدار Cloud Run (Pro بـ79 ريالًا/شهر · 649
  ريالًا/سنة؛ وتصريح موسم الاختبارات بـ299 ريالًا / 90 يومًا؛ والحزم 249 / 399 / 499؛ وحزمة الوصول
  الشامل 1,499؛ والأرصدة 39؛ وباقة الدفعة B2B بـ12,000/سنة)، والطبقة المجانية هي المكتبة كاملة، وكل
  أدوات الطيران الـ55، و5 أسئلة للكابتن عادل في اليوم. تأكّد من القيم الحيّة مقابل
  [`../../03-finance/`](../../03-finance/) قبل الإعلان.
- **الاستحقاق مملوك للخادم.** لا يوجد عَلَم من جهة العميل بمعنى «كل شيء مجاني» يجب تذكّر إطفائه —
  فالتطبيق يقرأ الاستحقاقات لتبويب الواجهة فقط، ولا يتيح أي مسار للعميل أن يكتب خطته بنفسه. أما
  المنح (الموظفون، ومقاعد المدارس، والعضوية المؤسِّسة) فلا ترفع الخطة إلا صعودًا.
- **رموز العروض الترويجية** يُتحقَّق منها من جهة الخادم وتنطبق على أول رسم فقط.
- **هيئة الزكاة والضريبة والجمارك (ZATCA)** — يجب أن يكون التسجيل في ضريبة القيمة المضافة والفوترة
  الإلكترونية عبر «فاتورة» قائمَين قبل تحصيل أي مبلغ؛ راجع
  [`../../04-compliance-ksa/`](../../04-compliance-ksa/).

## 5 — تذكيرات ما قبل الإطلاق

- تحتاج **الصفحات القانونية** (إخلاء المسؤولية، والشروط، وإشعار الخصوصية، والاسترداد) إلى اعتماد
  المحامي السعودي قبل الإعلان العلني.
- ينبغي أن يؤكّد المحامي **موقف إعادة توزيع GACAR / AIP** (البند P0-1).
- يغطّي **تقييم أثر PDPL (DPIA)** البيانات الشخصية في سجل الطيران ومنطقة الحساب — وهو بوّابة إطلاق،
  لا بند متابعة.
- إخلاء المسؤولية بعدم الارتباط مكوّن برمجي، لا نصّ يُعاد صوغه. ويجب أن يبقى ظاهرًا على كل سطح
  تنظيمي.

*جزء من جولة إطلاق فلاي قاكا الإرشادية. ليس استشارة قانونية.*
