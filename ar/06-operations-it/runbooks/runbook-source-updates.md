# Fly GACA — دليل تشغيل تحديثات المصادر

كيف تُبقي فلاي قاكا **GACAR** و**AIP** وبقية متن الهيئة العامة للطيران المدني متوافقة مع منشورات
الهيئة نفسها، وفق وتيرة AIRAC.

## الخلاصة

خط الأنابيب **نصفان بينهما ملف**. يجري الاكتشاف والاستخراج خارج مستودع التطبيق ويسلّمان ملف
`records.json` مُطبَّعًا؛ ثم يقارن السكربت من جهة التطبيق تلك الحزمة بالفهارس الحيّة، ويدمج الفروق
عند الطلب.

```bash
# From a clone of ay2m/FlyGACA, with the bundle at sync-input/records.json:
npm run sync:gaca         # dry run — diffs and reports new / changed / unchanged. Never writes.
npm run sync:gaca:apply   # merge metadata-only deltas, then re-normalise the corpus links
```

و`sync:gaca` **تشغيل تجريبي افتراضًا**. وتلك هي خاصية الأمان التي ينبغي تذكّرها: ترى الفروق دائمًا
قبل أن يمسّ شيءٌ المتن.

## ما الذي جرى ربطه

| المكوّن | المسار (في `ay2m/FlyGACA`) | الدور |
|-------|------|------|
| بيان المصادر | `public/data/sources.json` | عناوين URL الرسمية للهيئة العامة للطيران المدني، وإعداد AIRAC، والبصمات لكل مصدر. يملك خط الأنابيب البصمات — لا تحرّرها يدويًا. |
| محرّك الاستيراد / المقارنة | `scripts/sync-gaca.mjs` | يقرأ حزمة `records.json`، ويقارنها بالفهارس الحيّة، ويُبلِّغ، ويدمج (مع `--apply`). |
| قواعد الدمج | `scripts/lib/sync-merge.mjs` | أي نوع سجلّ يهبط في أي فهرس، وكيف يُفهرَس السجلّ بمفتاحه، وما الذي يُعدّ «متغيّرًا». |
| مُطبِّع الروابط | `scripts/normalize-corpus-data.mjs` (`npm run data:normalize`) | يعيد كتابة روابط المتن إلى الأشكال الدلالية التي يوجّه التطبيق عليها. مربوط ضمن `sync:gaca:apply`. |
| ملف الحداثة | `public/data/source-status.json` | لقطة عامة — آخر تفقّد، وAIRAC الحالي/التالي، وحالة كل مصدر. آمنة للشحن؛ ويمكن للتطبيق عرض «GACAR محدّث حتى …». |

أنواع السجلات وأين تهبط: **part** ← `gacar-index.json` · **ac** ← `reference-index.json` ·
**airport** ← `airports.json` · و**airspace** و**chart** ← فهرس كلٍّ منهما. وكل ذلك تحت
`public/data/`، ويُجلب في زمن التشغيل — فلا يدخل المتن حزمة JavaScript أبدًا.

## المصادر المتتبَّعة (مجموعة "كل شيء من الهيئة العامة للطيران المدني")

| id | ما هو | URL |
|----|------|-----|
| `gacar` | أجزاء GACAR وإطارها | https://gaca.gov.sa/en/Rules-and-Regulations-Category |
| `aip` / `aerodromes` / `charts` | AIP / eAIP، وAD 2، ومخططات VFR (مرتبطة بـ AIRAC) | https://gaca.gov.sa/web/en/aeronautical-information |
| `advisory-circulars` | AC-xxx | https://gaca.gov.sa/web/en/advisory-circulars |
| `notam` | NOTAM / PIB (حسّاسة زمنيًا) | https://gaca.gov.sa/web/en/notam |

## وتيرة AIRAC

تتبع حداثة AIP دورة AIRAC البالغة 28 يومًا. ويُحسب تاريخا السريان الحالي والتالي من المرساة في
`sources.json` (`airac.anchor`، `airac.cycleDays`). وتختم المصادر المرتبطة بـ AIRAC فهرسها
بـ**تاريخ سريان AIRAC**، لا بتاريخ التشغيل، بحيث يطابق التاريخ المنشور الدورة.

## كيف تجري دورة التشغيل

1. يجلب نصف الاكتشاف/الاستخراج كل مصدر مفعَّل من مصادر الهيئة العامة للطيران المدني ويُخرج حزمة
   `records.json` مُطبَّعة (`sync-input/records.json`)، يحمل كل سجلّ فيها `sourceUrl` الخاص به،
   و`revision` / `effectiveDate`، وبصمة `contentHash`.
2. يقارن `npm run sync:gaca` تلك السجلات بالفهارس الحيّة ويطبع ما هو جديد ومتغيّر وغير متغيّر —
   لكل مجموعة.
3. يدمج `npm run sync:gaca:apply` الفروق **ذات البيانات الوصفية فقط** (المدخلات الجديدة في الفهرس
   والمراجعات)، مع حفظ بصمة مصدر كل سجلّ كي تتمكّن المقارنة التالية من رصد المراجعة التالية، ثم
   يعيد تشغيل مُطبِّع الروابط.
4. أما **السجلات الحاملة للمتن** — أي شيء يحمل ملف PDF خامًا أو أصلًا من eAIP — فيُبلَّغ عنها بوصفها
   **مؤجَّلة**، ولا تُكتب. فتحويل مستند مصدر محدَّث إلى محتوى قراءة لكل جزء هو خطوة التحويل، وهي
   ليست تلقائية عن قصد.
5. عمليات إعادة البناء اللاحقة بعد تغيّر المتن: `npm run build:chunks` (فهرس استرجاع الكابتن عادل)،
   و`npm run parse:regulations` إن تأثّر جدول الإحالات المرجعية. ثم `npm run verify` قبل الإيداع.

## السلوك الآمن من الفشل

- **الافتراضي تشغيل تجريبي.** لا يُكتب شيء دون `--apply`.
- **لا يمكن تطبيق العيّنة الاصطناعية.** فإن كانت الحزمة الوحيدة الموجودة هي `records.sample.json`،
  يرفض `--apply` رفضًا صريحًا بدل كتابة سجلات `[SAMPLE]` في المتن الحقيقي.
- **عمليات الدمج تراكمية ومتماثلة التكرار.** فإعادة التشغيل بالحزمة نفسها لا تفعل شيئًا؛ والسجلّ
  الذي لم تتحرّك بصمته يُبلَّغ عنه بوصفه غير متغيّر.
- **المُطبِّع بلا فقد.** فأي رابط يعجز عن حلّه يحتفظ بسلسلته الأصلية ويُبلَّغ عنه، فلا يسقط شيء
  بصمت.

## الجدولة

**لا يوجد سير عمل مجدول يفعل ذلك اليوم** — إذ يُشحن `ay2m/FlyGACA` بلا مجلد `.github/workflows/`،
فيجب ربط CI (وأي مهمة cron) بمشروعك أنت أولًا. وعمليًا الوتيرة هي: شغّل نصف الاكتشاف، ثم
`npm run sync:gaca` قرابة خميس AIRAC وبعد أي منشور من الهيئة العامة للطيران المدني يبلغك خبره،
وراجِع الفروق، ثم طبّق.

وإن أتمتّه، فأبقِ الشكل نفسه من خطوتين — فالمهمّة المجدولة التي لا تشغّل إلا التشغيل التجريبي وتُبلِّغ،
مع ترك التطبيق لإنسان، هي النسخة التي لا يمكن أن تُفسد المتن بهدوء.

> [!NOTE]
> وصفت نسخ سابقة من هذه الصفحة `npm run check:sources` / `npm run update:sources`، وكاشطًا باسم
> `scripts/update-sources.js`، ومهمّة cron في `.github/workflows/update-sources.yml`، وبوّابة سلامة
> باسم `check-data.js`، وشجرة تجهيز `library/`، ومسارات `assets/data/`، وسرًّا باسم
> `FIREBASE_TOKEN` للنشر التلقائي. **لا وجود لأيٍّ من ذلك.** والأوامر أعلاه هي الحقيقية.

*دليل تشغيل تشغيلي — وليس استشارة قانونية. تبقى الهيئة العامة للطيران المدني المصدر ذا الحجية.*
