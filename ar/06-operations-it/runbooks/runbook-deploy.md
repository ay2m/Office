# دليل تشغيل — نشر Fly GACA (متجاوَز)

> [!WARNING]
> **أُحيل هذا الدليل إلى التقاعد في 2026-08-19 —** كان ينشر تطبيق ويب تقدّميًا (PWA) ثابتًا بلا بناء
> على **Firebase Hosting** بأمر `firebase deploy --only hosting`. ولم يعد شيء من ذلك قائمًا: لا
> مشروع Firebase، ولا `firebase.json`، ولا `.firebaserc`، ولا نسخة `sw.js` تُرفَع يدويًا، وقد حُذف
> مشروع `flygaca-firebase`. لا تُنفّذ أمرًا واحدًا من النسخة القديمة من هذه الصفحة.
>
> **ما الذي حلّ محلّه:** بناء Vite (`dist/`) يُنشر إلى دلو **Cloud Storage** خلف **موازن تحميل
> HTTPS**، مع توجيه `/api/*` إلى **خدمة Express 5 على Cloud Run** مسنودة بـ **Cloud SQL for
> PostgreSQL** — وكلها في **`me-central2` (الدمام)**.
>
> **اذهب بدلًا منه إلى:** `docs/RUNBOOK-deploy.md` في
> [`iflygaca/FlyGACA`](https://github.com/iflygaca/FlyGACA). فهو التسلسل المعتمد والمصان — يقيم مع الشيفرة،
> ولذلك لا يمكن أن ينحرف عن ملف Dockerfile ولا عن متغيّرات البيئة ولا عن مُشغِّل الترحيلات.
> و[`../hosting-facts.md`](../hosting-facts.md) هو الملخّص المختصر لما يعمل وأين.

## لماذا لا يزال هذا الملف موجودًا

يرتبط [`../hosting-facts.md`](../hosting-facts.md) بهذه الصفحة بوصفها نقطة الدخول من جهة «المكتب»
لسؤال «كيف يُنشَر هذا الشيء». وهي **لافتة إرشادية، لا نسخة مطابقة** — عن قصد، لأن تسلسل نشر منسوخًا
داخل مستودع وثائق يتقادم عند أول تغيير في ملف Dockerfile.

## شكل عملية النشر، للتوجيه فقط

| الخطوة | أين تجري |
|---|---|
| تزويد المشروع، ونسخة Cloud SQL، وعميل OAuth، ومدخلات Secret Manager | Google Cloud، لمرة واحدة |
| تطبيق المخطط | `server/migrations/`، عبر مُشغِّل الترحيلات أحادي الاتجاه |
| نشر واجهة API | `gcloud run deploy` من جذر المستودع — تُضبط الأسعار والأسرار على الإصدار |
| نشر تطبيق الصفحة الواحدة | `npm run build`، ثم مزامنة `dist/` إلى الدلو |
| وضع الواجهة الأمامية | موازن تحميل HTTPS: خلفية الدلو على `/*`، ومجموعة نقاط نهاية الشبكة بلا خادم على `/api/*` |
| التجديدات | Cloud Scheduler ← `POST /api/billing/renew` مع `CRON_SECRET` |
| المدفوعات | ويبهوك Moyasar + مرحلة التأكيد من خادم إلى خادم |

أمران يستحقّان أن تحملهما في ذهنك قبل فتح دليل التشغيل الحقيقي:

- **يجب أن يكون Cloud Run وCloud SQL في الإقليم نفسه** — إذ تصل الخدمة إلى قاعدة البيانات عبر مقبس
  unix خاص بـ Cloud SQL، فلا توجد قائمة عناوين IP مسموح بها ولا وكيل جانبي.
- **السعر غير المضبوط ليس صفرًا صامتًا بالريال** — بل تفشل صيغة الدفع بصوت عالٍ بدلًا من ذلك. اضبط
  كل سعر تنوي البيع به.

لا يوجد نشر بأمر واحد، و`npm run deploy` في مستودع المنتج يفشل عمدًا مع مؤشِّر إلى دليل التشغيل
الحقيقي.

  `02-legal/`).
- ينبغي أن يؤكّد المحامي موقف إعادة توزيع GACAR / AIP (البند P0-1).
- تُوجَّه صناديق بريد التواصل وفق
  [`../../02-legal/email-routing.md`](../../02-legal/email-routing.md).
