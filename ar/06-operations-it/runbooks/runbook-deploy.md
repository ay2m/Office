# دليل تشغيل — نشر Fly GACA على Firebase Hosting

أُنجز بناء موقع المرحلة 1 (الصفحة الرئيسية، والمكتبة، والقارئ، ولوحة معلومات المطارات + الخريطة، وعارض المخططات،
والصفحات القانونية). يأخذ دليل التشغيل هذا الموقع إلى الإنتاج على `flygaca.com`.

**خبر سار:** يعمل Firebase Hosting على **خطة Spark المجانية** — فلا حاجة إلى ترقية Blaze أو
بطاقة دفع للنشر. (لا تلزم Blaze إلا لاحقًا، من أجل Cloud Functions في المرحلة 2.)

**ما الذي يُنشر:** صفحات HTML، و`assets/` (CSS وJS والخطوط والصور، وكذلك كتالوجات
`assets/data/` المُولَّدة، ونصوص الأجزاء وصور المخططات)، و`sw.js` والبيان (manifest). أمّا
المتن الخام في `library/` فمستثنى بموجب `firebase.json`، فلا تُرفع أبدًا ملفات PDF المصدرية البالغة نحو 1 غيغابايت.

---

## الإعداد لمرة واحدة

1. **ثبّت واجهة Firebase CLI** (تحتاج إلى Node.js، الموجود أصلًا على جهازك):
   ```bash
   npm install -g firebase-tools
   ```

2. **سجّل الدخول** بحساب Google الذي يملك مشروع Firebase
   (`flygaca@gmail.com`):
   ```bash
   firebase login
   ```

يحتوي المستودع أصلًا على `firebase.json` (إعداد الاستضافة) و`.firebaserc` (الذي يشير
إلى مشروع `flygaca-firebase`)، فلا شيء آخر يلزم ضبطه.

---

## النشر

من جذر المستودع:

```bash
cd ~/Documents/Claude/flygaca/flygaca
firebase deploy --only hosting
```

عند الانتهاء، تطبع واجهة CLI **عنوان URL للاستضافة** — `https://flygaca-firebase.web.app`. افتحه:
يكون الموقع بكامله حيًّا عبر HTTPS، وكل ما يحتاج إلى HTTP (المكتبة، والقارئ، والخريطة، وعارض
المخططات) يعمل الآن.

---

## ربط النطاق المخصص — flygaca.com

1. لوحة تحكم Firebase ← مشروعك ← **Hosting** ← **Add custom domain**.
2. أدخل `flygaca.com`.
3. تمنحك Firebase سجلات DNS (سجل A، أو TXT للتحقق). أضفها لدى
   مُسجِّل نطاقك.
4. تزوّد Firebase شهادة SSL تلقائيًا (قد يستغرق ذلك مدة تصل إلى نحو 24 ساعة).

---

## تحديث الموقع لاحقًا

أعد تشغيل `firebase deploy --only hosting` بعد أي تغيير. وعند تغيير شفرة الموقع،
**ارفع `VERSION` في `sw.js`** (مثل `flygaca-v1` ← `flygaca-v2`) كي يلتقط الزوار العائدون
التحديث بدلًا من نسخة قديمة مخزّنة مؤقتًا.

**اختياري — عمليات نشر تلقائية:** يمكن لسير عمل GitHub Actions أن ينشر عند كل دفعة إلى
`main`. ويحتاج إلى رمز CI من Firebase أو حساب خدمة مخزَّن كسرّ في GitHub. أعدّ
ذلك حالما يتأكد عمل النشر اليدوي.

## تذكيرات ما قبل الإطلاق

- **الصفحات القانونية مسوّدات** — اطلب من المحامي السعودي مراجعة الشروط وإشعار الخصوصية
  وإخلاء المسؤولية قبل الإعلان العلني عن الموقع (انظر `office/lawyer-brief.md`).
- أنشئ صناديق البريد للتواصل المشار إليها في الموقع: `i@flygaca.com` و
  `i@flygaca.com`.
- تستضيف المكتبة الآن نص GACAR ومواد مشتقة من AIP — وينبغي تأكيد موقف إعادة التوزيع
  (P0-1) من قِبل المحامي.

*جزء من جولات إعداد المرحلة 0 / المرحلة 1 لـ فلاي قاكا.*
