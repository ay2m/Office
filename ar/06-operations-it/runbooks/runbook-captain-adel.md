# دليل تشغيل — نشر الكابتن عادل (بوابة محادثة RAG)

الكابتن عادل هو **الدماغ الكامن خلف `/chat`**: يسترجع مقاطع GACAR ويسأل Gemini عن الإجابة، موثَّقة
بالإحالة إلى الجزء/القسم بالضبط. وهو ليس وحدة نشر منفصلة — بل مجموعة مسارات داخل خدمة Express
الواحدة على Cloud Run (`/api/chat` و`/api/feedback`، إضافةً إلى السطح المرخّص `/v1/ask`). ونشر
الكابتن عادل يعني نشر واجهة API.

> [!NOTE]
> هذه الصفحة تخصّ الكابتن عادل **داخل المنتج** (`iflygaca/FlyGACA`). أما الخدمة المستقلة الكامنة خلف
> `captadel.com` فتقيم في [`iflygaca/Captain-Adel`](https://github.com/iflygaca/Captain-Adel) ولها صفحاتها
> الخاصة `runbook-captadel-*` في هذا المجلد. لا تخلط بين الاثنتين.

---

## ما تحتاج إليه أولًا

1. **مفتاح Gemini API** — aistudio.google.com ← *Get API key*. يُخزَّن في Secret Manager باسم
   `genai-api-key` ويصل إلى الخدمة بوصفه `GOOGLE_GENAI_API_KEY`. ولا يُودَع في المستودع أبدًا.
2. **متن RAG مبنيًّا داخل الصورة.** يعيد `npm run build:chunks` توليد
   `public/data/rag-chunks.json`؛ وينسخه ملف Dockerfile إلى الصورة كي لا يحتاج فهرس BM25 إلى أي جلب
   عند الإقلاع البارد.
3. **خدمة Cloud Run نفسها** — مُزوَّدة وفق `docs/RUNBOOK-deploy.md` في
   [`iflygaca/FlyGACA`](https://github.com/iflygaca/FlyGACA). ولا دخل لـ Firebase ولا Cloud Functions ولا
   خطة Blaze في الأمر.

---

## النشر

لا يوجد أمر نشر خاص بالمحادثة. أعِد بناء المتن إن تغيّر، ثم انشر واجهة API تمامًا كما يصف دليل
التشغيل في مستودع المنتج (`gcloud run deploy` من جذر المستودع، مع ضبط الأسرار والأسعار على
الإصدار).

يعمل `assertRequiredConfig()` قبل أن يرتبط المستمع، فالإصدار الذي ينقصه `DATABASE_URL` أو يحمل
`SESSION_SECRET` أقصر ممّا يجب يفشل في فحص سلامته بدل أن يُخطئ بالرمز 500 لاحقًا. ويُعيد
`GET /healthz` الرمز 503 حتى تستجيب قاعدة البيانات.

وحالما يصير الإصدار حيًّا، اطرح سؤالًا عن GACAR على `/chat` — مثلًا *"What are the VFR weather
minima?"*. وينبغي أن تحمل الإجابة **مصادر** ترتبط ارتباطًا عميقًا داخل قارئ المكتبة.

## كيف يعمل

```
/chat (SPA)  ──POST /api/chat──▶  Cloud Run (Express 5)
                                       │
                          gateway.ts   │  quota + rate limits + SSE framing
                                       │
                          corpus.ts    │  BM25 over rag-chunks.json
                                       │
                      captain-adel.ts  │  Genkit → Gemini, cited answer
```

نقطتا تصميم لهما أثر تشغيلي:

- **التأصيل يُحسَب من جهة الخادم، لا يُطلَب من النموذج.** فدون عتبة الرفض *لا يُستدعى النموذج
  إطلاقًا* — ويحصل المستخدم على رفضٍ يستشهد بالنظام بدلًا من ذلك. فلا يمكن أن يخرج رقم GACAR ملفَّق
  لمجرّد أن النموذج كان واثقًا.
- **حُرّاس النظام مُختبَرون بوحدات اختبار.** فقواعد «غير مرتبطة» و«تعليمي فقط» تقيم في وحدتها
  الخاصة مع اختبار يُفشل البناء إذا أُسقطت إحداها. وهي التوأم الخادمي لإخلاء المسؤولية على مستوى
  الموقع — عامِلها كما تعامل مكوّن إخلاء المسؤولية: لا تُعِد صياغتها ارتجالًا.

## الضبط والتحكم في التكلفة

| الرافعة | المكان | الافتراضي |
|---|---|---|
| النموذج (الطبقة المجانية) | Gemini عبر Genkit | `gemini-2.5-flash` |
| النموذج (طبقة Pro) | يُختار لكل طلب بحسب خطة المتصل | `gemini-2.5-pro` |
| المقاطع المسترجَعة | `RETRIEVE_K` | `6` |
| درجة الرفض دونها | `REFUSE_SCORE` | `1.5` |
| درجة التأصيل الكامل | `GROUNDED_SCORE` | `4` |
| الأسئلة المجانية في اليوم | `CHAT_FREE_DAILY_LIMIT` | `5` |
| الأسئلة لكل حزمة أرصدة مشتراة | `CHAT_CREDIT_PACK_SIZE` | `50` |
| مفتاح إيقاف المحادثة | `CHAT_ENABLED` | `true` |
| حدّ الاندفاع لكل حساب | في `gateway.ts` | 20 دورًا/دقيقة |
| الحدّ العام لكل عنوان IP | في `gateway.ts` | 30 طلبًا/دقيقة |
| حدّ واجهة API المرخّصة لكل مفتاح | في `gateway.ts` | 60 طلبًا/دقيقة |

الحصّة اليومية هي أداة التحكم الحقيقية في التكلفة، وهي **لكل حساب، في كل يوم** — فالطبقة المجانية
خمسة أسئلة في اليوم، والنظير من جهة العميل لتلك السياسة مفروض بالاختبارات مقابل نواة الخادم، فلا
يمكن أن ينحرف أحدهما عن الآخر. أما محدِّدات الاندفاع فذاكرتها لكل نسخة: تحمي من الحلقات المنفلتة
وإساءة الاستخدام العابرة، لا من هجوم موزّع.

و`CHAT_ENABLED=false` هو التوقّف الاضطراري إذا انفلت إنفاق النموذج.

## التحديث لاحقًا

- **هل غيّرت المتن؟** `npm run build:chunks`، وأودِع
  `public/data/rag-chunks.json` المُعاد توليده، وأعِد نشر واجهة API.
- **هل غيّرت شخصية الكابتن عادل؟** عدّل وحدة الموجّه في `server/src/`، وشغّل مجموعة اختبارات الخادم
  (سيخبرك اختبار الحُرّاس إن كنت قد أزلت قاعدة)، ثم أعِد النشر.
- **هل دوّرت مفتاح Gemini؟** أضِف نسخة جديدة إلى السرّ `genai-api-key` وانشر إصدارًا جديدًا — إذ
  تُقرأ الأسرار عند بدء الإصدار.
- **هل غيّرت سياسة التسعير أو الحصّة؟** نواة الخادم هي مصدر الحقيقة؛ ويُفشل اختبار النظير من جهة
  العميل في مستودع المنتج البناءَ إذا حدّثت أحدهما دون الآخر.

## استكشاف الأخطاء وإصلاحها

| العَرَض | السبب المرجَّح |
|---|---|
| تُرجع المحادثة رفضًا لسؤال تجيب عنه المكتبة بوضوح | جاءت درجة الاسترجاع دون `REFUSE_SCORE` — تحقّق من إعادة بناء المتن بعد آخر مزامنة محتوى. |
| كل طلب يُرجع 503 | الخدمة تعمل لكن قاعدة البيانات لا تستجيب — و`/healthz` مرهون بها. |
| `429 rate_limited` | بلوغ محدِّد الاندفاع (20 دورًا/دقيقة لكل حساب). متوقَّع تحت حِمل مبرمَج. |
| نفاد الحصّة لمستخدم مدفوع | افحص سجلّ الاستحقاق — فالخطة والأرصدة مملوكة للخادم ولا يكتبها إلا مسارا الفوترة والمنح. |
| أخطاء نموذج / حصة من Google | حدود Gemini API على مشروع المفتاح. ارفع الحصة أو اخفض حركة المرور. |
| تصل الإجابات بلا استشهادات | ملف المتن غير موجود في الصورة (`CORPUS_URL`) — خطوة النسخ في ملف Dockerfile. |

## تذكيرات ما قبل الإطلاق

- الكابتن عادل **ذكاء اصطناعي تعليمي**. يقول ذلك إخلاء المسؤولية على الصفحة وحُرّاس الخادم معًا.
  أبقِ الاثنين.
- المتن مادة منشورة من الهيئة العامة للطيران المدني فقط. وتقع إشعارات NOTAM والطقس الحيّة خارج
  النطاق عمدًا، ويرفضها الموجّه.
- أكّد موقف إعادة توزيع GACAR مع المحامي السعودي (P0-1) قبل الإطلاق العام.
