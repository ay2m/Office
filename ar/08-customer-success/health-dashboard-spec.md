# مواصفات لوحة معلومات صحة العميل

## الغرض

تحدّد هذه الوثيقة كيفية تشغيل نموذج تسجيل درجة الصحة لدى فلاي قاكا (Fly GACA)
وتحويله إلى لوحة معلومات عاملة وأداة احتساب قابلة للتشغيل. وهي تنفّذ المنهجية
المُعرَّفة في [`docs/customer-health-scoring.md`](customer-health-scoring.md)
وتُشغّل الأدلة الإجرائية الاستباقية (المعرّض للخطر، والتجديد، والتوسّع).

التنفيذ المرجعي هو
[`scripts/health_score.py`](../scripts/health_score.py).

## مصادر البيانات والمدخلات

تقرأ أداة الاحتساب ملف CSV يكون فيه كل صف عميلًا واحدًا وكل بُعد مسجّلًا مسبقًا
من 0 إلى 100. ويتوفّر ملف عيّنة في
[`scripts/sample_customers.csv`](../scripts/sample_customers.csv).

| العمود | النوع | الوصف |
|--------|------|-------------|
| `customer` | نص | اسم الحساب |
| `segment` | نص | مدارس الطيران / مشغّلو الطيران العارض / منظمات الصيانة والإصلاح والعمرة (MROs) / المشغّلون التجاريون |
| `plan` | نص | Starter / Professional / Enterprise |
| `usage` | 0–100 | بُعد استخدام المنتج |
| `engagement` | 0–100 | بُعد التفاعل |
| `support` | 0–100 | بُعد صحة الدعم |
| `financial` | 0–100 | بُعد المالية / العقد |
| `sentiment` | 0–100 | بُعد المشاعر |

في بيئة الإنتاج، تُشتق درجات هذه الأبعاد من قياسات المنتج عن بُعد، ونظام الدعم،
وإدارة علاقات العملاء (CRM)، وبيانات الاستبيانات؛ وتتعامل هذه المواصفات معها
بوصفها مدخلات.

## أبعاد التسجيل والأوزان

الدرجة المركّبة هي مزيج مرجّح (مجموع الأوزان 1.0)، مطابق لما في
`customer-health-scoring.md`:

| البُعد | العمود | الوزن |
|-----------|--------|--------|
| استخدام المنتج | `usage` | 30% |
| التفاعل | `engagement` | 20% |
| صحة الدعم | `support` | 20% |
| المالية / العقد | `financial` | 15% |
| المشاعر | `sentiment` | 15% |

`composite = 0.30·usage + 0.20·engagement + 0.20·support + 0.15·financial + 0.15·sentiment`

## نطاقات الدرجة والأدلة الإجرائية المُفعَّلة

| النطاق | المدى | الخطوة التالية الموصى بها |
|------|-------|-----------------------|
| صحّي | 80–100 | [الدليل الإجرائي للتوسّع](expansion-playbook.md) — اسعَ إلى النمو / المناصرة |
| محايد | 60–79 | [الدليل الإجرائي للتجديد](renewal-playbook.md) — عزّز القيمة، وراقِب |
| معرّض للخطر | 0–59 | [الدليل الإجرائي للحسابات المعرّضة للخطر](at-risk-playbook.md) — تدخّل، وصعّد |

## المخرجات والتقارير

تنتج الأداة لكل عميل: الدرجة المركّبة، والنطاق، والدليل الإجرائي الموصى به. كما
تطبع ملخصًا للمحفظة (عدد الحسابات، ومتوسط الدرجة، والعدد لكل نطاق). وتُصدِر الراية
`--csv` مخرجات قابلة للقراءة آليًا لإدخالها في لوحة معلومات ذكاء الأعمال (BI).

ينبغي للوحة معلومات الإنتاج أن تصوّر إضافةً إلى ذلك: توزيع الدرجات حسب النطاق،
والاتجاه عبر الزمن، والحسابات حسب الشريحة/الباقة، والتعمّق إلى البُعد الأضعف لكل
حساب.

## كيفية تشغيل النص البرمجي

```bash
# Human-readable table
python3 scripts/health_score.py scripts/sample_customers.csv

# Riskiest accounts first
python3 scripts/health_score.py scripts/sample_customers.csv --sort

# CSV output for BI ingestion
python3 scripts/health_score.py scripts/sample_customers.csv --csv
```

يتطلّب Python 3 (المكتبة القياسية فقط — لا حاجة إلى تثبيت).

## وتيرة التحديث

تُعاد عملية احتساب درجات الصحة **أسبوعيًا** (وفق `customer-health-scoring.md`).
والحسابات التي تسجّل أقل من 60 تُخطِر تلقائيًا مدير نجاح العملاء (CSM) المعيّن
وتدخل الدليل الإجرائي ذا الصلة.
