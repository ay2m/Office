# سياسة الأمن

## الإصدارات المدعومة

استخدم هذا القسم لإبلاغ الناس بأي إصدارات مشروعك
مدعومة حاليًا بالتحديثات الأمنية.

| الإصدار | مدعوم               |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| 5.0.x   | :x:                |
| 4.0.x   | :white_check_mark: |
| < 4.0   | :x:                |

## الإبلاغ عن ثغرة

استخدم هذا القسم لإبلاغ الناس بكيفية الإبلاغ عن ثغرة.

أخبرهم بالجهة التي يتوجّهون إليها، وكم مرة يمكنهم توقّع الحصول على تحديث بشأن
الثغرة المُبلَّغ عنها، وماذا يتوقّعون في حال قُبِلت الثغرة أو
رُفِضت، وما إلى ذلك.
